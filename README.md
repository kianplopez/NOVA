# NOVA — Projet BTS SIO SLAM

Site e-commerce fictif réalisé en HTML et CSS dans le cadre du BTS SIO SLAM.

## Description du projet

NOVA est une boutique en ligne fictive proposant des chaussures, des vêtements et des accessoires.

## Le site comprend 4 pages

- Accueil
- Boutique
- Inscription
- Panier

## Technologies utilisées

- HTML5
- CSS3
- GitHub (+ GitHub Pages)

## État d'avancement du projet

Le site NOVA est encore en cours de développement. Les principales pages du site ont été réalisées.
La page panier a également été créée, mais son fonctionnement n'est pas encore finalisé (notification rouge lorsqu'on clique sur « Ajouter un produit »).
Les liens dans le footer sont cliquables, mais il n'y a pas encore de véritables comptes sur les réseaux sociaux.
